# Security

Report a vulnerability in the Cueston CLI, MCP server or the hosted server at
`https://app.cueston.com/api/mcp` by email to support@cueston.com (subject "Security"), not in a public issue.
Include steps to reproduce and the version (`npx cueston --version`).

We reply within 3 business days and tell you when a fix ships. Please give us a reasonable
time to fix the issue before you publish it.

Only the latest release on npm gets security fixes.
